# 公开交接与隐私边界

## 这份公开项目是什么

这是从完整项目工作区提炼的**去隐私化活跃线与续工资料**，不是私有目录的完整镜像。原始历史工程、素材和私有记录保留在维护者本机，不因制作公开交接而删除或改写。

公开版本的目标是让别人能够：

- 获取当前独立插件、对应源码和真实面板预览。
- 理解产品契约、模块职责、状态所有权、已修复堵点和未覆盖平台。
- 用公开构建入口修改 TOX，并运行适当的规则、CI 与宿主验收。
- 在不接触私有聊天、密钥或素材的情况下继续下一版开发。

## 明确不公开的内容

- API key、token、密码、私钥、证书、凭据文件、带凭据 URL 和认证配置。
- 个人身份与联系方式、朋友聊天、公司／客户信息、内部服务地址和不可公开的业务资料。
- 原始会话、agent wire／rollout、临时附件索引、本机用户目录和绝对路径。
- 历史代码雨工程、旧交付 ZIP、原始艺术素材、第三方设计 HTML、未确认再分发许可的媒体。
- 私有宿主测试驱动、自动执行钩子、测试输出、渲染中间文件、缓存、日志和 `.DS_Store`。
- 随 FFmpeg 下载的完整二进制包。插件只保存固定清单和验证逻辑，安装时另取上游包并保存相应许可。

这些内容不会通过「改扩展名」「压缩整个目录」或「仅加入 `.gitignore`」变成可公开材料。

## 当前公开范围

- 当前独立 TOX、七个维护模块、帮助文本、格式目录和公开构建脚本。
- 中英文使用说明、项目上下文、开发指南、堵点记录、更新记录与第三方声明。
- 已检查不含本机私有路径的当前面板预览。
- 去路径化的验收结果 JSON；其中的 `<project>` / `<managed>` 是占位符，不是可执行安装路径。
- 公开 CI 工作流和纯 Python 测试。它们不需要仓库密钥，使用 GitHub 托管 runner 和上游公开下载。

## 发布门槛

1. **候选文件**：只显式复制公开白名单；扫描私钥、常见 token、硬编码凭据、带凭据 URL、本机路径和业务隐私。扫描器先用合成违规样本验证会拒绝，输出只列文件和规则，不回显秘密。
2. **Git 索引与历史**：检查实际暂存 blob 和将推送的历史，确认没有私有文件或早期遗留；`.gitignore` 不能清除历史泄漏。
3. **最终归档**：从冻结提交生成归档，核对成员、CRC／可读取性、链接、校验值与扫描结果；候选失败时不得覆盖上一个有效包。
4. **远端回读**：确认远端提交、Actions、版本化文档和 Release 附件；需要下载时比较真实附件字节与 SHA-256，而不只检查上传返回成功。
5. **人工复核**：自动扫描不是绝对隐私保证。截图、姓名、聊天、路径和第三方许可还需按实际内容检查。

## 后续贡献者与 agent

- 先读 `AGENTS.md` 和 `PROJECT_CONTEXT.md`，不要把历史私有材料当作公开产品的必要依赖。
- 新增文件时先判断它属于公开源码、公开文档、合成测试数据还是私有证据；默认不公开真实用户素材。
- 如果发现问题报告中误含密钥，停止扩大分发并建议撤销／轮换；不要仅删除工作区文件就宣称历史已清理。
- 如果要公开新的历史版本、素材或原始交接文档，需要另行确认其隐私与许可范围，不能由本页的现有授权自动扩大。
