# 项目堵点、已证实原因与处理记录

本页保留会影响后续开发判断的技术问题。症状和解决范围来自实际项目记录；不包含个人聊天、公司信息、私有路径或原始测试素材。修改对应代码前同时阅读 `TEST_REPORT.md`。

## 1. Windows 与 FFmpeg 自动配置

| 症状 | 已证实原因 | 当前处理与边界 |
|---|---|---|
| Windows 提示「FFmpeg 自动配置目前仅支持 macOS」 | 1.4 `host_arch()` 只允许 macOS，不是用户漏装 FFmpeg | 1.5 增加 win64 清单、下载、安装、PE 与原生执行验证；不是只改文案 |
| Windows 编码器检查把 VideoToolbox 当成必需项 | Apple 专用的 `h264_videotoolbox` / `hevc_videotoolbox` 被混入平台要求 | `platform_encoders()` 按平台过滤；当前目录 win64 为 29 项、macOS 为 31 项，不把计数当通用常量 |
| BtbN ZIP 找不到预期 EXE | 实际上传包可能多一层发布目录，布局不只有根目录或 `bin/` | 只按白名单提取两个 EXE，兼容根目录、`bin/` 和发布子目录；不释放整个压缩包 |
| 包名正确但执行身份不正确 | 文件名和 ZIP 哈希不能替代目标架构、版本及构建能力检查 | 校验 MZ/PE、`0x8664`、版本与构建参数，并在 Windows runner 真正执行 |
| 本机下载大文件超时 | 本机网络没有完成完整 Windows 包下载 | 不记为本机完整验证；最终完整包由 Windows runner 下载并执行通过 |
| Windows CI 通过是否等于朋友机器上的 TD UI 已通过 | 不是。CI 验证的是外部二进制的下载与执行 | 物理 Windows TD UI、GPU、旧版 TD 和网络组合仍需单独验证 |

## 2. 下载、线程与宿主生命周期

| 症状 | 已证实原因 | 当前处理与边界 |
|---|---|---|
| TD 内下载发生 TLS 拒绝 | 内嵌 Python 默认 CA 路径不可用 | 使用 certifi 或 macOS 系统 CA；不得关闭证书校验 |
| Rosetta 环境选错包 | 仅看进程机器类型会误认宿主架构 | 优先 `hw.optional.arm64`，再回退机器信息；Rosetta 通过不代表原生 Intel Mac 通过 |
| 后台下载调用 TD API 失败 | 后台线程读取了 `op()` 等宿主对象 | 主线程先取得模块、参数和编码器清单，后台只运行纯 Python；UI 更新回主线程 |
| 下载或渲染被重新初始化清空 | 活动阶段再次执行完整 `initialize()` | 活动任务忽略重复初始化；首次配置和独立导出都要覆盖 |
| 下载失败后留下半配置目录 | 暂存、安装锁与最终目录职责不清 | 固定哈希、原子安装、失败／取消清理；真实指针取消仍未单独验收 |
| 含空格的 `.cparm` 文案使后续参数消失 | 未按宿主格式加引号 | 构建时保留引号，并读取真实参数清单验证 |

## 3. 渲染、音频与源状态

| 症状 | 已证实原因 | 当前处理与边界 |
|---|---|---|
| 离线渲染拿不到完整音频 | 当前 TD build 的 Audio File In 恒为时间切片，即使写入 `timeslice=False` | 离线源改用 Wave／Script CHOP 或缓存录制；实时模式仍要求 Time Slice |
| NumPy 音频通道／样本颠倒 | 误设数组轴向 | `CHOP.numpyArray()` 与 `scriptOp.copyNumpyArray` 使用 `(channels, samples)` |
| 连续设置容器和编码器失败 | 参数 DAT 回调可能延迟一帧，菜单尚未重建 | 联动赋值间手动调用对应参数的 `changed()`；宿主实测确认 |
| 暂停时间线后调度停止 | 普通帧回调也随全局时间线暂停 | 使用经确认的独立时间参考 `delayRef=op.TDResources` 推进；分别验证首尾帧和恢复 |
| 节点统计完成但文件少最后一帧 | GPU 回读／写盘晚于当前 cook | 分阶段停止写入、跨独立时钟提交、关闭、等待完成、恢复并实际解码 |
| 编码完成后点击取消却误报取消 | 没有先区分进程仍活动与已成功退出 | 先检查实际进程状态，分别处理活动取消、已完成和已失败；保留中间素材 |
| 删除导出组件后源和时间线未恢复 | 清理仍引用已失效 DAT/COMP | 保留必要的已建立恢复函数和状态，不再解析已删除节点 |
| 换父容器或改名后来源失效 | 相对路径基点靠猜或接线方式不适用于嵌套 TOX | 用宿主 `relativePath()` 生成并解析；嵌套验证经宿主 In TOP 连接，不只看 `connect()` 无报错 |

## 4. 离线构建与发布

| 症状 | 已证实原因 | 当前处理与边界 |
|---|---|---|
| `toeexpand` / `toecollapse` 返回非零但产物可能存在 | 工具退出码不能单独代表往返失败 | 以工具输出、重新展开、TOC／必需文件和模块字节核对为准，不忽略真正损坏 |
| `.text` 内容或长度损坏 | 该文件含 27 字节头，长度在 `0x19–0x1A` 大端 uint16 | 使用公开构建脚本的头部写入函数；单个 DAT 不超过 65535 字节 |
| 压回后缺节点或清单异常 | TOC 路径、根级必需文件或注释行处理不当 | 保留清单格式和根级 `.build` 等文件；连续构建并重新展开比较 |
| 中文文件名影响工具或 Release 附件名 | 离线工具可能无法展开，上传工具也可能改写附件名 | 构建暂存与 Release 使用可移植 ASCII 名；原私有文件不必改名或删除 |
| 私有构建脚本不能直接公开 | 含本机路径、宿主自动执行钩子和测试输出位置 | 公开 `scripts/apply_source.py` 只接受显式路径参数，写入模块、版本与帮助，不调用 TD、不注入测试 |
| 后续文档提交被误写成 CI 已运行提交 | CI 的产品提交与最终文档提交不同 | 记录准确 run、提交和作业；输入未变可复用证据，但不能改写运行身份 |

## 5. 仍未覆盖

- 物理 Windows TouchDesigner UI、真实指针下载取消、Windows ARM64、其他操作系统、旧版 TD 和原生 Intel Mac。
- 长片压力、磁盘写满、所有容器×编码器×分辨率组合及完整广播规范。
- 第三方源的任意状态可重复性。固定种子只覆盖已理解并适配的引擎，不保证摄像头、网络流或独立时钟可倒带。
